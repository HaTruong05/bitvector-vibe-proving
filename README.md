# LLM-Assisted Formal Verification of Bit-vector Invertibility Conditions in Rocq

## Repository Contents

`BVList.v` is a Coq library for dependently typed bitvectors. It consists of a raw
bit-vector type representing simply-typed bit-vectors, and a dependently-typed
bit-vector type that is generated by instantiating a functor (also defined in the
library) with the raw bit-vector module.

`InvCond.v` consists of the proofs of the 19 equivalences over raw bitvectors.

`DepInvCond.v` consists of the same proofs over dependently-typed bit-vectors.

Many of the proofs in `BVList.v` and `InvCond.v` benefit from the
recostruction tactics of the [Coqhammer](https://github.com/lukaszcz/coqhammer) tool.
`Reconstr.v` defines some tactics locally to make it easier to use CoqHammer.

## LLM Assistance

Some of the proofs were done with assistance from Google Gemini and many others done with assistance from
Claude Code. Unfortunately, we weren't able to recover chat logs for
our interactions with Gemini, since the platform's data retention period of three
months had already expired by the time we were preparing this directory.

The `llmHist` directory contains all the files that were either necessary for or a
by-produce of using Claude Code. The directory also contains a `README.md` file
that explains the structure of the directory.

## New Library Additions

The following definitions were added to `BVList.v` to support the new invertibility equivalence proofs:

| Definition                   | Description                                             |
| ---------------------------- | ------------------------------------------------------- |
| [`bv_sle`](BVList.v#L1199)   | Signed less-than-or-equal                               |
| [`bv_sgt`](BVList.v#L1251)   | Signed greater-than                                     |
| [`bv_sge`](BVList.v#L6347)   | Signed greater-than-or-equal                            |
| [`bv_udiv`](BVList.v#L4773)  | Unsigned division                                       |
| [`bv_urem`](BVList.v#L4784)  | Unsigned remainder                                      |
| [`bv2int`](BVList.v#L10167)  | Unsigned bitvector-to-integer interpretation (Z-valued) |
| [`sbv2int`](BVList.v#L11156) | Signed bitvector-to-integer interpretation (Z-valued)   |

## Building

Compilation requires Coq version 8.20.0. To compile, run in `root`:

1. `coq_makefile -f _CoqProject -o Makefile`
2. `make`

For more detailed installation instructions including Coq installation instructions,
see [`INSTALL.md`](INSTALL.md).
